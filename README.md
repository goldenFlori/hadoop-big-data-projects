# Hadoop Big Data Projects

Hands-on Hadoop projects (MapReduce, Pig, Hive on HDFS), built on a local
Dockerized single-node cluster.

## Projects
1. Log processing — summarize & analyze server logs (MapReduce)
2. Sales analysis — revenue insights (MapReduce)
3. Tourism survey — joins, filters, aggregations (MapReduce/Hive/Pig)
4. Faculty data — schema design & transformation (Hive/Pig)
5. E-commerce — customer filtering & analytics (Hive/Pig)
6. Salary analysis — department & employee analytics (Hive/Pig)

## Stack
Apache Hadoop 3.3.1 · HDFS · MapReduce · Pig · Hive · Docker
